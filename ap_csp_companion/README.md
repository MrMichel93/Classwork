# AP CSP Companion Activities

These short activities supplement the Python programming sequence with AP CSP
topics that are best learned through investigation, discussion, modeling, and
written explanation. They are not Python assignments.

| Activity | Suggested time | Connects to |
|---|---:|---|
| [01 Data Representation](01_data_representation.md) | 1-2 periods | Variables, strings, files, and data collections |
| [02 Networks and the Internet](02_networks_and_internet.md) | 1-2 periods | Files, APIs, and asynchronous programming |
| [03 Cybersecurity and Privacy](03_cybersecurity_and_privacy.md) | 1-2 periods | Input validation, passwords, and data files |
| [04 Impacts of Computing](04_impacts_of_computing.md) | 2-3 periods | Data projects and student-selected applications |

Each activity has a student deliverable and an evidence checklist. Use local
examples and school-approved sources when students research current events or
real services.
