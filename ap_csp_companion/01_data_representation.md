# Data Representation

**Suggested time:** 1-2 class periods  
**Connects to:** variables, strings, lists, dictionaries, JSON, and file I/O

## Learning Goals

- Explain that computers represent information as bits.
- Convert small positive integers between binary and decimal.
- Describe why the same bit pattern can represent different information when
  interpreted with a different encoding.
- Identify one tradeoff made when storing or compressing data.

## Activity

1. Convert the decimal values 5, 12, 42, and 255 into 8-bit binary.
2. Decode `01001000 01101001` using a character encoding reference. Explain
   why a computer needs an agreed-upon encoding to display text.
3. Compare these representations of a student record:

   ```text
   101010
   "42"
   {"student_id": 42, "name": "Sam"}
   ```

   State what information is preserved or missing in each version.
4. Choose a photo, audio clip, or text document used in school. Explain one
   reason it might be compressed and one possible consequence of compression.

## Student Deliverable

Submit a one-page explanation or three-slide presentation that includes:

- the four binary conversions;
- a decoded-character explanation;
- the student-record comparison; and
- one compression tradeoff.

## Evidence Checklist

- Binary values use the correct place values.
- The explanation distinguishes data from its interpretation.
- The compression example names both a benefit and a limitation.
- Technical terms are defined in the student's own words.
